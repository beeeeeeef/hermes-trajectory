# 轨迹面板：最近 100 条与柔和视觉

用户在实际使用后确认：顶部时间条不要；进入面板应直接停在最新消息；只保留最近 100 条；用颜色区分角色、增加圆角、减少硬分隔线；展开收起要更顺；失败标记只在有结构化证据时出现。

## 决定
- 删除全场索引与时间条；`MAX_ENTRIES` 为 100，读取历史先取尾部 100 条，合并后仍只留 100。
- 面板挂载后滚到底部；用户主动向上翻看时不强制跟随新消息，回到接近底部后恢复跟随。
- 角色使用现有主题色的浅底胶囊：user=accent，assistant=blue，tool=orange，system=tertiary；不再铺满整行，也不使用大写标签。
- 记录行改为圆角卡片，去掉全宽分隔线和列头；时间仍在左侧，详情为卡片内浅底块。
- 展开使用 `grid-template-rows` 过渡 180ms；`prefers-reduced-motion` 时关闭过渡。
- 失败标记只根据实时 `tool.complete` 的结构化结果：对象 `success === false` 或有非空 `error`。历史记录通常没有输出，继续显示 `args only`，不猜测失败。

## 非目标
不改数据 RPC、不恢复时间条、不做分页、不做 Markdown 渲染、不改上下文插件。

## 验收
- 150 条历史只保留最后 100 条；首尾 key 正确。
- 进入面板滚到最底部；向上翻看时不被新消息拽回。
- 结构化失败显示 `failed`，纯文本 `Error:` 不标记。
- 340/380/600px 无横向溢出；真实 Hermes 重载后人工确认圆角、色块、展开动画。
